# Konsep Dokumentasi Penggunaan Aplikasi Web INDOTIX

## Tujuan Dokumen
Dokumen ini disusun sebagai panduan penggunaan aplikasi web INDOTIX dari sisi pengguna akhir. Isi dokumen dibatasi pada alur yang benar-benar terverifikasi dari route Laravel, page component Inertia React, dan tampilan aktual aplikasi yang dijalankan secara lokal.

## Scope Yang Akan Didokumentasikan
1. Beranda dan navigasi utama.
2. Registrasi akun pengguna.
3. Login akun pengguna.
4. Menjelajah produk melalui halaman kategori.
5. Menggunakan pencarian, filter, sort, dan pemilihan tanggal pada halaman kategori yang mendukung tanggal.
6. Membuka detail produk.
7. Menambahkan produk retail ke keranjang.
8. Meninjau keranjang belanja dan halaman checkout retail.
9. Mengelola profil pengguna pada halaman pengaturan profil.

## Scope Yang Tidak Akan Diarang
1. Alur yang memerlukan data atau kondisi yang belum diverifikasi secara visual.
2. Fitur admin, mitra, dan dashboard internal.
3. Detail proses pembayaran yang bergantung pada popup gateway pembayaran eksternal.
4. Klaim fitur yang tidak terlihat pada route, controller, atau page component publik.

## Konsep Struktur Dokumen DOCX
1. Sampul dokumen.
2. Ringkasan aplikasi web INDOTIX.
3. Persiapan sebelum menggunakan aplikasi.
4. Panduan navigasi beranda.
5. Panduan membuat akun.
6. Panduan login.
7. Panduan mencari dan menjelajah produk.
8. Panduan membuka detail produk.
9. Panduan keranjang dan checkout retail.
10. Panduan mengelola profil.
11. Catatan penting penggunaan.

## Prinsip Penulisan
1. Bahasa Indonesia yang formal, jelas, dan mudah diikuti.
2. Setiap langkah didasarkan pada tampilan aktual aplikasi.
3. Tidak menggunakan asumsi fitur di luar yang berhasil diverifikasi.
4. Screenshot disisipkan dekat dengan langkah yang dijelaskan.
